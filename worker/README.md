# Прокси примерки

Сайт и виджет публичные, поэтому ключ сервиса в них класть нельзя. Этот воркер Cloudflare
хранит ключ fal.ai как секрет и выполняет два действия:

- `avatar` — фото человека по фигуре: снимок тела по меркам (+ фото лица) → FLUX Kontext
  (~$0.04 за фото, делается один раз, пока мерки те же);
- `tryon` — вещь из карточки товара на этом человеке → FASHN Try-On v1.6 (~$0.075 за фото).

## Подключение (один раз)

1. Ключ: зарегистрироваться на https://fal.ai, пополнить баланс, создать API key.
2. Воркер: `cd worker && npx wrangler login && npx wrangler deploy` — в ответ придёт адрес
   вида `https://mannequin-photo.<аккаунт>.workers.dev`.
3. Секрет: `npx wrangler secret put FAL_KEY` и вставить ключ.
4. Демо-сайт: GitHub → Settings → Secrets and variables → Actions → Variables → `GEN_URL` = адрес воркера.
   Маркетплейсу этот адрес указывается в `data-endpoint` у скрипта виджета.
5. Сайты, которым можно звать прокси, — `ALLOWED_ORIGINS` в `wrangler.toml`.

Локально: `VITE_GEN_URL=https://… npm run dev`.
Без адреса прокси виджет показывает фигуру по меркам и совет по размеру, без фото в вещи.
