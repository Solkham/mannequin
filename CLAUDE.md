# Примерка на себя — виджет для маркетплейсов

Покупатель на маркетплейсе открывает карточку вещи и жмёт «Примерить на себя»: один раз вводит
рост, вес и обхваты (по желанию — фото лица или в полный рост) и видит фото человека своей фигуры
(или себя) именно в этой вещи из карточки + какой размер брать. Продаётся маркетплейсам как виджет.

## Команды
- `npm run dev` — сайт локально; `npm run build` — сборка в `dist/`; `npm test` — все проверки.
- Модели: `python scripts/export_anny.py` (нужен `pip install -r scripts/requirements.txt`, ~1 мин на CPU).
- Публикация: `.github/workflows/pages.yml` собирает и выкладывает на GitHub Pages при пуше в `main`.

## Устройство
- `index.html` + `src/demo.ts` — демо-страница товара (фото товара ссылкой или загрузкой, тип, название;
  можно передать в адресе `?img=…&kind=tee&title=…`) и код для встраивания.
- `src/tryon/widget.ts` — окно примерки в Shadow DOM: мерки и фото (хранятся в браузере), фото человека,
  примерка, совет по размеру. `KINDS` — типы вещей → сетка размеров и категория примерки.
- `src/tryon/embed.ts` → `dist/widget.js` (`vite.widget.config.ts`) — виджет одной строкой:
  `<script src=".../widget.js" data-endpoint="...">` + кнопки с `data-tryon-image/kind/title`.
- `src/tryon/figure.ts` — тело по меркам (Anny, `src/body.ts`, `src/rig.ts`, `src/stage.ts`) снимается
  спереди вне экрана; из снимка сервис делает фото живого человека этой фигуры.
- `src/tryon/api.ts` + `worker/` — прокси Cloudflare с ключом fal.ai: `avatar` (FLUX Kontext, с лицом —
  Kontext multi) и `tryon` (FASHN v1.6). Адрес прокси — переменная `GEN_URL` → `VITE_GEN_URL`.
- `src/sizing.ts` + `src/data/items.json` — подбор размера по стандартным российским сеткам.
- `scripts/export_anny.py` — Anny (NAVER, Apache-2.0) → `public/models/anny-{female,male}.glb` + `anny-meta.json`.

## Решения
- Обхваты точны (до 1 мм), вес — мягкая цель: у Anny мало полноты, на плюс-сайзе манекен легче на 6–14 кг.
  Плотность 1040 кг/м³ — калибровка, а не физика.
- Сетки — стандартные российские, а не с карточек маркетплейсов (решение владельца).
- Решение владельца (06.10.2026): не 3D-одежда кодом (позы, подиум, нарисованные ткани — убраны), а ИИ-примерка
  настоящего фото товара из карточки на фото человека с пропорциями покупателя. Продукт — виджет для маркетплейсов.
- Ключи платных сервисов — никогда в сайт (он публичный), только секретом в `worker/`.
- Проверять глазами: после правок окна — скриншоты на компьютере и телефоне (Playwright,
  `executablePath: '/opt/pw-browsers/chromium'`, `--use-angle=swiftshader`); сервис подменять `page.route`.
