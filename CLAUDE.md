# Манекен — заметки для работы над проектом

Персональный 3D-манекен в браузере: человек вводит рост, вес и обхваты, выбирает вещь
(или загружает фото своей), видит её на «себе» в позах и показе на подиуме и получает
вердикт по размеру по зонам тела. Без сервера: всё считается и хранится в браузере.

## Команды
- `npm run dev` — сайт локально; `npm run build` — сборка в `dist/`; `npm test` — все проверки.
- `?perf` в адресе — раз в 3 с в консоль идут кадры/с, время подгонки фигуры и ткани.
- Модели: `python scripts/export_anny.py` (нужен `pip install -r scripts/requirements.txt`, ~1 мин на CPU).
- Публикация: `.github/workflows/pages.yml` собирает и выкладывает на GitHub Pages при пуше в `main`.

## Устройство
- `scripts/export_anny.py` — Anny (NAVER, Apache-2.0) → `public/models/anny-{female,male}.glb`:
  сетка, 10 морфов (рост, вес, грудь, талия, бёдра ↑/↓), скелет 104 кости, квантование
  `KHR_mesh_quantization` (морфы int16, нормали int8, веса uint8). `anny-meta.json` — кольца замеров,
  части тела вершин, головы костей и их сдвиги по морфам, плотность для веса.
- `src/body.ts` — смешивание морфов, замеры (выпуклая оболочка кольца = сантиметровая лента,
  объём × плотность = вес), подбор морфов под фигуру. Без Three.js.
- `src/rig.ts` — скелет подгоняется под фигуру, позы направлениями сегментов.
- `src/stage.ts` — сцена: свет, позы стоит/идёт/сидит/лежит/показ, 4 ракурса, бирки зон, камера за моделью.
  Манекен деревянный без лица: голова сглажена в «яйцо» (`makeFaceless`), волокна и швы сборки — в шейдере
  (`woodMaterial`), 5 оттенков дерева вместо тонов кожи.
- `src/sizing.ts` + `src/data/items.json` — размерная логика и каталог (стандартные российские сетки).
- `src/garment.ts` — вещь на манекене: край по непрерывной функции (`inside`), драпировка по сетке
  «длина × угол» (`shapeTube`), складки и заломы в шейдере, низ (юбка, хвост рубашки, низ худи и куртки)
  — симулируемая ткань `src/cloth.ts` (PBD), принт/фото спереди и сзади.
- `src/fabrics.ts`, `src/photo.ts` — ткани и принты кодом; рельеф плетения (bump, гаснет издалека) и
  поверхность по ткани (`fabricFinish`: sheen у трикотажа/вискозы, лак у пуховика); своё фото: вырезание фона.
- `src/photoshoot.ts` + `worker/` — «Фото в этой вещи»: снимок сцены + текст → прокси Cloudflare Worker
  (ключ fal.ai — секрет воркера) → FLUX Kontext. Адрес прокси — переменная репозитория `GEN_URL`
  (в сборку как `VITE_GEN_URL`); без неё кнопка просит подключить сервис. Подключение — `worker/README.md`.

## Решения
- Обхваты точны (до 1 мм), вес — мягкая цель: у Anny мало полноты, на плюс-сайзе манекен легче на 6–14 кг.
  Плотность 1040 кг/м³ — калибровка, а не физика.
- Сетки — стандартные российские, а не с карточек маркетплейсов (решение владельца).
- Манекен деревянный и без лица (решение владельца): реалистичными должны быть посадка и ткань, а не кожа.
  Подсветка зон на одетом манекене — только на ткани.
- Ключи платных сервисов — никогда в сайт (он публичный), только секретом в `worker/`.
- Ткань спит, когда тело неподвижно 1,5 с; на сенсорных устройствах сетка ткани реже (64×16).
- Проверять глазами: после любой правки одежды — скриншоты всех вещей во всех позах (Playwright,
  `executablePath: '/opt/pw-browsers/chromium'`, `--use-angle=swiftshader`).
